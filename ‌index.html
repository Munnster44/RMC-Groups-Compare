README — What this app does

This app compares the Email address column in a Google Groups member listing with both the email and AdditionalEmail columns in an Alumni file. It adds the matching alumnus's first and last name to every Google Groups row.

How to use it

  1. Select the Google Groups Excel or CSV file.
  2. Select the Alumni Excel or CSV file.
  3. If a workbook contains several sheets, choose the correct sheet.
  4. Click Match Email Addresses.
  5. Review the totals and preview, then click Export Excel Workbook.

Matching rules

  • Emails are matched without regard to upper/lower case.
  • Spaces around the Google Groups address are ignored.
  • The complete Google Groups email address may appear anywhere inside the Alumni email or AdditionalEmail cell, so labels, notes, names or other additional data in those cells do not prevent a match.
  • Blank addresses are not matched.
  • If an email is contained in more than one Alumni record, the Groups row is marked Ambiguous; the app does not guess.

Excel output

The exported workbook contains Google Groups Matched with First Name and Last Name as its first two columns, followed by all original Groups columns, Match Status and Matched Alumni Field. Records are sorted by Last Name and then First Name; records without a matched name appear at the end. Unmatched rows are highlighted yellow and ambiguous rows are highlighted red in both the preview and Excel output. The Alumni Not in Groups worksheet contains the complete Alumni records whose email fields contain none of the Google Groups addresses. Birth Date Records and Date of Death Records contain complete Alumni records with values in those respective columns. The workbook also contains Unmatched, Ambiguous, and Summary worksheets. The source files are read only in your browser and are not uploaded by this app.

Accepted header variations: The app ignores capitalization, spaces, underscores and hyphens. For example, Email Address, email_address and EmailAddress are treated alike.
